1. Resumen de la Migración

¿Qué cambiamos?

Componente Antes Después (Google)
Base de datos MongoDB Firebase Firestore
Autenticación JWT propio Firebase Authentication
LLM (texto) Gemini via Emergent Gemini API directo
Speech-to-Text OpenAI Whisper Google Cloud Speech-to-Text
Text-to-Speech Web Speech API Google Cloud Text-to-Speech
Backend FastAPI (Python) Firebase Cloud Functions
Hosting Servidor propio Firebase Hosting

3. Paso 1: Configurar Firebase

3.1 Acceder a Firebase Console

  1. Abre tu navegador y ve a: https://console.firebase.google.com/
  2. Inicia sesión con tu cuenta de Google
  3. Selecciona tu proyecto "WORKLISH"

3.2 Habilitar Firebase Authentication

  1. En el menú izquierdo, haz clic en "Authentication"
  2. Clic en "Comenzar"
  3. En la pestaña "Sign-in method", habilita:
    • ✅ Correo electrónico/contraseña
    • ✅ Google (opcional)

3.3 Crear Cloud Firestore

  1. En el menú izquierdo, haz clic en "Firestore Database"
  2. Clic en "Crear base de datos"
  3. Selecciona "Modo de producción"
  4. Ubicación: "us-central1"
  5. Clic en "Habilitar"

3.4 Configurar Reglas de Seguridad

En Firestore → Reglas, usa:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
    
    match /progress/{docId} {
      allow read, write: if request.auth != null && resource.data.userId == request.auth.uid;
    }
    
    match /practices/{docId} {
      allow read, write: if request.auth != null && resource.data.userId == request.auth.uid;
    }
  }
}

3.5 Obtener Configuración de Firebase

  1. En Firebase Console → ⚙️ Configuración del proyecto
  2. Desplázate a "Tus apps" → clic en icono Web </>
  3. Nombre: "worklish-web"
  4. ✅ Marca "Configurar Firebase Hosting"
  5. Clic en "Registrar app"
⚠️ IMPORTANTE: Copia y guarda la configuración que aparece: 
const firebaseConfig = {
  apiKey: "AIzaSy.....................",
  authDomain: "worklish-XXXXX.firebaseapp.com",
  projectId: "worklish-XXXXX",
  storageBucket: "worklish-XXXXX.appspot.com",
  messagingSenderId: "123456789",
  appId: "1:123456789:web:abcdef123456"
};

4. Paso 2: Habilitar APIs de Google Cloud

4.1 Desde Google Cloud Console

  1. Ve a: https://console.cloud.google.com/
  2. Asegúrate de que el proyecto "WORKLISH" esté seleccionado
  3. Ve a APIs y servicios → Biblioteca

4.2 Habilitar cada API

API Buscar Acción
Speech-to-Text "Cloud Speech-to-Text API" Clic en HABILITAR
Text-to-Speech "Cloud Text-to-Speech API" Clic en HABILITAR
Gemini "Generative Language API" Verificar habilitada

4.3 Método alternativo (CLI)

gcloud auth login
gcloud config set project TU_PROJECT_ID

gcloud services enable speech.googleapis.com
gcloud services enable texttospeech.googleapis.com
gcloud services enable generativelanguage.googleapis.com
gcloud services enable cloudfunctions.googleapis.com

4.4 Crear Cuenta de Servicio

  1. Ve a Credenciales → + CREAR CREDENCIALES → Cuenta de servicio
  2. Nombre: "worklish-speech-service"
  3. Rol: "Propietario"
  4. Crea una clave JSON y guárdala de forma segura

7. Paso 5: Migrar el Backend

7.1 Instalar dependencias

cd functions

npm install @google-cloud/speech
npm install @google-cloud/text-to-speech
npm install @google/generative-ai
npm install firebase-admin
npm install firebase-functions
npm install cors
npm install busboy

7.2 Configurar API Key de Gemini

firebase functions:config:set gemini.api_key="TU_GEMINI_API_KEY"

# Verificar
firebase functions:config:get

7.3 Copiar credenciales

cp ~/Downloads/worklish-xxxxx-adminsdk.json functions/service-account.json

7.4 Código de Cloud Functions

El archivo functions/index.js completo está en la guía Markdown. Contiene:

  • health - Health check
  • practiceText - Práctica de escritura con Gemini
  • practiceVoice - Práctica de voz con Speech-to-Text
  • videoCall - Conversación con IA + TTS
  • textToSpeech - Generar audio
  • getUserProfile - Obtener perfil de usuario

8. Paso 6: Migrar el Frontend

8.1 Instalar Firebase SDK

cd frontend
npm install firebase

8.2 Crear archivo de configuración

Crea frontend/src/lib/firebase.js con:

  • Configuración de Firebase
  • Funciones de autenticación (login, registro, logout)
  • Funciones de API para llamar a Cloud Functions

8.3 Crear AuthContext

Crea frontend/src/contexts/AuthContext.jsx para manejar el estado de autenticación con Firebase.

8.4 Actualizar App.js

Envolver la app con AuthProvider y usar useAuth en rutas protegidas.

9. Paso 7: Configurar Firebase Studio

9.1 Abrir Firebase Studio

  1. Ve a: https://idx.google.com/
  2. Clic en "New project" → "Import from GitHub"
  3. Selecciona tu repositorio worklish
  4. Espera a que se configure

9.2 En la terminal de Firebase Studio

# Instalar dependencias
cd frontend && npm install
cd ../functions && npm install

# Login en Firebase
firebase login --no-localhost

# Verificar proyecto
firebase projects:list

9.3 Probar localmente

# Terminal 1: Emulador de Functions
cd functions
firebase emulators:start --only functions

# Terminal 2: Frontend
cd frontend
npm start

10. Paso 8: Deploy a Firebase Hosting

10.1 Construir el Frontend

cd frontend
npm run build

10.2 Deploy de Functions

cd ../functions
firebase deploy --only functions

Verás las URLs de tus funciones:

✔ Deploy complete!

Function URL (health): https://us-central1-worklish-XXXXX.cloudfunctions.net/health
Function URL (practiceText): https://us-central1-worklish-XXXXX.cloudfunctions.net/practiceText
...

10.3 Actualizar URL en Frontend

Actualiza FUNCTIONS_URL en firebase.js con la URL real.

10.4 Deploy del Frontend

cd ..
firebase deploy --only hosting

10.5 Deploy Completo

firebase deploy
✅ ¡Listo! Tu app estará en: https://worklish-XXXXX.web.app

11. Solución de Problemas

Error: "Permission denied"

gcloud services enable cloudfunctions.googleapis.com
gcloud services enable cloudbuild.googleapis.com

Error: "Invalid API key"

  1. Google Cloud Console → Credenciales
  2. Verifica que las APIs correctas estén habilitadas
  3. Regenera la key si es necesario

Error: "CORS policy"

Verifica que cors esté configurado en functions/index.js

Error: "User not found"

Verifica que Authentication esté habilitado en Firebase Console
